# Case-study image assets

Drop screenshots/photos here to replace the dashed placeholders on the
`/projects/*.html` pages. Filenames are already wired into each page — just
add the file, then follow the HTML comment next to each placeholder to swap
the `.shot-ph` block for an `<img>`.

Recommended: 16:9, ≤ ~1600px wide, optimized PNG/JPG/WebP.

| File | Page | What it should show |
|------|------|---------------------|
| `forager1-sim.png`      | forager1   | The robot driving in the Gazebo Harmonic simulation |
| `terrafirma-map.png`    | terrafirma | The web map with a suitability heatmap overlay |
| `terrafirma-config.png` | terrafirma | A species suitability YAML config file |
| `pathfinder-app.png`    | pathfinder | The app with a drawn coverage polygon + exclusion zones |
| `crawler1-sim.png`      | crawler1   | The skid-steer model in the Gazebo simulation |
| `millwright-fusion.png` | millwright | LLM-authored toolpaths in the Fusion 360 CAM workspace |
| `millwright-machine.png`| millwright | The Nomad 3 desktop CNC mill |

The architecture / flow diagrams on each page are inline SVG — no image files
needed for those; edit them directly in the page markup.
